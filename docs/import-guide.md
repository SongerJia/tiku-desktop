# 题库转换导入规范（供 AI 执行）

> 用途：把手头任意格式的题目资料（Word 复制文本、PDF 抽取、网页、手写 OCR、聊天记录等）转换成「知识记忆小助手」可直接导入的 **CSV / Excel** 文件。
> 本文档写给 AI 助手：**按本规范的约束执行转换，产出标准文件**，不要自行发挥字段或格式。

---

## 0. 目标格式

产出两种之一（二选一，用户指定）：

- **CSV 文件**：UTF-8 编码**带 BOM**（`\uFEFF` 开头，防止 Excel 打开乱码）；每行一条题目；字段含逗号时用双引号包裹，双引号转义为 `""`。
- **Excel 文件**（.xlsx）：一张工作表，第一行是表头，逐行题目。

> 无论哪种，**表头必须严格等于下表 16 列**，顺序不能变。

## 1. 表头与列规范（16 列，顺序固定）

| # | 列名 | 必填 | 规则 |
|---|------|------|------|
| 1 | 科目 | 是 | 如 `建设工程法规`。同一批可统一；单题也可单独填 |
| 2 | 章节 | 否 | 如 `施工许可制度`；没有就留空 |
| 3 | 题型 | 是 | 见 §2 题型枚举（写标准写法，如 `单选`） |
| 4 | 题干 | 是 | 完整题目文字；可含标点、括号、公式（文本形式） |
| 5 | 选项A | 否 | 单选/多选必填；判断/问答**留空** |
| 6 | 选项B | 否 | 同上 |
| 7 | 选项C | 否 | 同上 |
| 8 | 选项D | 否 | 同上 |
| 9 | 选项E | 否 | 有第 5 个选项才填，否则留空 |
| 10 | 选项F | 否 | 有第 6 个选项才填，否则留空 |
| 11 | 答案 | 是 | 见 §3 答案格式 |
| 12 | 得分关键词 | 否 | 仅问答题需要；多个关键词用**分号 `;`** 分隔 |
| 13 | 解析 | 否 | 答案解析；没有留空 |
| 14 | 难度 | 否 | 整数 1~5；默认 3 |
| 15 | 来源 | 否 | 如 `2024真题`、`教材P85`；没有留空 |
| 16 | 听力音频 | 否 | 音频地址（本地路径或 http 链接）；没有留空 |

## 2. 题型枚举（标准写法）

| 标准写法 | 含义 | 别名（转换时可识别，但产出请用标准写法） |
|---------|------|--------------------------------|
| `单选` | 单项选择，答案唯一 | 单选题 / 单项选择 / single |
| `多选` | 多项选择，答案 ≥2 个 | 多选题 / 多项选择 / 不定项 / multiple |
| `判断` | 对错题 | 判断题 / 对错题 / judge |
| `问答` | 主观题（简答/论述/案例/名词解释/填空） | 简答 / 论述 / 案例 / 名词解释 / 填空 / essay |

> 判断/问答的选项列**必须留空**，系统会自动处理。

## 3. 答案格式（按题型）

| 题型 | 答案写法 | 示例 |
|------|---------|------|
| 单选 | 一个选项字母 | `A` |
| 多选 | 字母连写（不空格） | `ABD` |
| 判断 | `对` 或 `错` | `对` |
| 问答 | 留空（参考答案请放进「解析」或交给关键词判分） | 留空 |

判断答案可识别写法（产出时统一用 `对`/`错`）：对/正确/是/√/T/1；错/错误/否/×/F/0。

## 4. 转换铁律（AI 必须遵守）

1. **不编造**：原内容里没有的答案/解析，一律留空，绝不猜测补写。
2. **忠实还原**：题干、选项、答案逐字保留原样，不改写、不简化、不翻译（除非用户明确要求）。
3. **数量一致**：输入 47 题就输出 47 行，不多不少；序号丢失没关系，但题数不能错。
4. **无法判断就标注**：某道题原始格式残缺（比如选项只有 A、B），照实输出、留空缺列，不要自行补 C、D。
5. **问答题给采分点**：如果原文有答案要点（分点/关键词），转成「得分关键词」，分号分隔；不要整段塞进关键词列。
6. **去噪**：题目序号（`1.`、`第1题`）、来源说明、页眉页脚等非题目内容，**不进入任何列**。
7. **选项字母统一大写**：`a` → `A`。
8. **空白列处理**：没有内容的列填**空**（CSV 中相邻分隔符之间留空），不要写 `无`、`-`、`N/A`。

## 6. 常见原始格式 → 列的转换提示

| 原始内容长这样 | 转到哪列 |
|---------------|---------|
| `1. 项目管理中，C 代表？`（序号+题干） | 序号去掉，文字进「题干」 |
| `A 计划 B 实施 C 检查 D 处理`（同行选项） | 拆开 → 选项A~D |
| `A、计划 B、实施` / `A. 计划` / `A) 计划` | 归一为选项列，字母大写 |
| `答案：C` / `【答案】C` / `正确答案是 C` | 「答案」列 |
| `解析：xxx` / `答案解析：xxx` | 「解析」列 |
| `多选题：答案 AB` | 题型 `多选`，答案 `AB` |
| `判断题：（）` 选项是 正确/错误 | 题型 `判断`，答案 `对`/`错`，选项列留空 |
| 简答题的要点列表（①②③） | 「得分关键词」列（分号分隔） |
| `2019年真题` / `来自教材` | 「来源」列 |

## 7. 验收清单（产出前自检）

- [ ] 表头 16 列与 §1 完全一致、顺序一致
- [ ] 每行「科目」「题型」「题干」「答案」非空（问答答案可空）
- [ ] 单选/多选至少有 2 个选项；判断/问答选项列为空
- [ ] 多选答案字母数 ≥2 且都在选项范围内
- [ ] 问答题关键词用分号分隔
- [ ] 难度取值 1~5
- [ ] CSV 为 UTF-8 带 BOM；含逗号/引号/换行的字段已正确转义
- [ ] 题数与源内容一致，无编造

## 8. 交付方式

- 产出文件：`题库导入.csv`（或 `.xlsx`），放在用户指定位置。
- 如果内容里没有题目（纯资料/教材讲解），**告知用户"这些内容适合进知识库而不是题库"**，不要硬转。
