## 1. 项目定位

**「题库 + 知识库 + 错题复习 + 习惯激励 + 跨设备同步」五合一的本地学习工具。**

- 纯本地单用户，SQLite 存储，无后端依赖
- 云同步基于 GitHub Gist（免费、可审计），支持多设备 LWW 合并
- 面向考证/备考人群（样例数据为二级建造师）

**技术栈**：Electron 31 + Vue 3.4 + better-sqlite3 11 + Vditor（MD 渲染/编辑）+ pdfjs-dist（PDF 阅读）+ electron-builder（打包）+ electron-updater（自动更新铺垫）+ vite-plugin-electron

## 2. 功能全景（八大模块）

### ① 首页学习驾驶舱（`Home.vue`）
总览统计 / 今日目标进度 / 7 天答题趋势（SVG）/ 学习日历热力图（近 120 天，悬停显示专注分钟）/ 薄弱点 Top5 / 每日任务 Quest（+20XP）/ 习惯打卡（+5XP）/ 每日回顾翻转卡 / 专注计时 / 卡片记忆 / **考试倒计时**（≤7 天红色闪烁）/ 专注概览卡

### ② 题库管理（`Knowledge.vue` + `BankManager.vue`）
科目/章节分类树（增删改、级联删题）/ 题目 CRUD（单题/批量：移动章节/打标签/设难度/删除）/ Excel 导入向导（重复检测：跳过/覆盖/全新增，展示明细）/ 题库 JSON 导出 / 分页 + **题干+选项+解析+关键词全文搜索** / 题目编辑器（**Ctrl+V 粘贴图片**、听力音频选文件、材料题、问答题采分点）/ 模拟卷组卷（规则抽题、计时计分）

### ③ 答题引擎（`Quiz.vue`）
六模式：练习 / 模拟考试（倒计时+提前交卷）/ 背题 / 错题重练 / 收藏复习 / **智能复习（SM-2）** / **答题卡导航**（跳题+四态标记）/ 逐题解析（含知识库相关文档推荐）/ 断点续做 / 答完即时反馈动画 + **四档反馈（忘记/困难/记得/简单）** + 标记已掌握 / **TTS 语音朗读**（题干/解析）/ 成绩历史记录（Stats 曲线数据源）

### ④ 错题与复习（SM-2 间隔重复）
`wrong_books` 记录 quality/ease/interval；答错 quality<3 → 间隔重置 1 天、ease 降；答对 → 1→6→×ease 复利；连对 3 次或手动标记 → 毕业；到期桌面通知 / 错题本（错因标注、相似题、**复习节奏曲线**、导出 PDF）/ 算法抽在 `electron/sm2.js`（纯函数，8 条单测）

### ⑤ 知识库（`KbLibrary.vue` + `KbReader.vue`）
MD / PDF 导入（抽取文本+块级检索+hash 去重）/ 全屏三栏阅读（Vditor IR 编辑 / PDF 懒渲染缩放）/ 块高亮 / 阅读进度记忆 / 文档互链 / **知识↔题目双向推荐** / **关联图谱**（SVG 环形布局，点击跳文档）

### ⑥ 统计与激励（`Stats.vue`）
题型/章节正确率 / **章节正确率雷达图**（最弱 6 章）/ 成绩历史曲线 / XP 成长体系（升级成就+庆祝动画）/ 学习周报导出 / 连续打卡统计

### ⑦ 我的·数据与设置（`Profile.vue`）
**云同步**（GitHub Gist：JSON 分块 + 图片独立文件 + LWW 合并 + **冲突明细可视化** + 自动同步 60 分钟兜底）/ **备份恢复**（每日自动留 5 份、损坏自动恢复防变砖、备份列表弹层）/ 数据管理（导出错题本/笔记 Markdown、**全量数据导出 ZIP**、清理无用图片、清空本地数据）/ 偏好（每日目标、**目标考试日**、每日提醒时间、外观主题、字体缩放）/ 科目管理 / 关于

## 4. 数据模型（24 张表）

`users` `categories` `questions` `answer_records` `wrong_books` `favorites` `notes` `settings` `papers` `paper_questions` `question_tags` `kb_docs` `kb_blocks` `kb_tags` `kb_links` `xp_logs` `habits` `habit_checks` `review_logs` `focus_sessions` `cards` `materials` `kb_highlights` `kb_doc_links`

**关键设计**：
- 云同步身份列：主表均带 `client_id`；外键按 `*_cid` 引用解析（跨设备 id 不错位）
- `wrong_books`：`ease`/`interval`（SM-2）、`UNIQUE(user_id, question_id)` 支撑 UPSERT
- 软删除：业务表 `deleted=0` 过滤；同步/导出统一 LWW 按 `updated_at` 覆盖
- 知识库子表（blocks/tags/links）无 client_id，跨设备跟随「远端胜出的文档」整体重建

### 阶段一：核心修复（7 项）

### 阶段二：功能打磨（两批 8+8 项）

### 阶段三：大文件拆分（17 轮，收官）
`db.js` **2995 → 242 行（-92%）**，拆出 21 个独立模块；同步建立 136 条集成测试基线

**拆分过程中发现并修复的真实 bug（共 5 个）**：
1. `idx_q_material` 索引引用未 ALTER 的列 → **全新库初始化必炸**（老库升级路径掩盖）
2. `wrong_books`/`notes` 缺 `UNIQUE(user_id, question_id)` → UPSERT 依赖缺失
3. `exportData` 对无 `deleted` 列的表统一加 WHERE → 改为动态检测
4. `mergeRemote` cfg 索引错位：kb_highlights 误用 cards 列、kb_doc_links 误用 materials 列 → 含高亮/双链的快照合并会 SQL 报错
5. **`mergeRemote` 冲突计数恒为 0**：`getByCid` 只 `SELECT id`，`ex.updated_at` 恒 undefined → 冲突判断永不触发（同步"冲突 N 条"一直是假 0）

## 7. 已知问题 / 技术债 / 待办

### 未完成（明确挂起）
- **安装包发布**：代码就绪（electron-builder 配置完整），`npm run dist` 由用户自行执行。⚠️ `build.publish` 已指向 `github.com/songerjia/tiku-desktop`，发布前确认仓库归属；Windows 无代码签名会有 SmartScreen 提示（正常）
- **知识库 PDF 原文展示优化**（pdfjs 渲染细节）
- **音频题跨设备同步**：`audio_url` 存文件名，音频文件未纳入 Gist 同步（仅本机）；ZIP 导出已含 audio 目录

### 迭代约定（务必遵守）
1. **改 db 层先跑 `npm run test:db`**——136 条断言是安全网，拆分模式：抽一块 → 跑基线 → 无回归再抽下一块
2. **sqlite 依赖模块的合并必须在 init() 中 sqlite 赋值后**（`Object.assign` 放 `_tryOpen` 之后），否则拿到 undefined
3. **备份三件套（autoBackup/listBackups/restoreBackup）勿拆**——`_recoverFromBackup` 在合并前调用 `this.listBackups()`，拆出会导致启动崩溃
4. 搜索保持 LIKE 子串（中文分词问题，勿盲推 FTS5；量级千级毫秒级返回）
5. 新增业务表：建表放 `db-schema.js` initSchema，老库升级列放 migrateSchema addColumn；同步合并需在 `db-sync.js` cfg 数组登记列清单（**注意 cfg 索引顺序**）
6. 新增同步表：主表必须带 `client_id` + `updated_at`；无 cid 的子表按"远端胜出整体重建"模式

## 8. 常用命令

```bash
npm run dev        # 开发（vite + electron 热更新）
npm run build      # 构建前端 + electron 产物（dist/ + dist-electron/）

npm test           # 全部纯 node 测试（parser/xlsx/sync/sm2/kb）
```
